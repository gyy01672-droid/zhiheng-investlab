## 公开新闻监测（已替代微博）

无需账号、API密钥或服务额度。持仓预警、股票咨询及后台资料更新统一使用上市公司公告、东方财富公司新闻检索、新浪财经7×24快讯。风险预警页可检查各来源、查看真实发布时间与抓取时间；新闻输入本机语言模型作为证据。

每轮巡检结束后120秒再次检查，新闻与公告索引缓存60秒；快讯读取最近100条，优先按来源股票标签匹配，缺少标签时才匹配代码或完整简称。过滤超过72小时及异常未来时间的信息，保留辟谣降级、去重和来源失败记录。有限条数、网络和新闻收录可能造成延迟或漏报，不保证发布后两分钟内送达，也不等于社交平台全量舆情。

程序需保持运行；页面通知需页面打开，系统通知需浏览器授权。负面关键词只触发核查提醒，不执行抛售。已取消微博入口和运行调用，旧安装文件不再使用，源码包不包含微博适配器与依赖。

公开页面：https://finance.sina.com.cn/7x24/ 。实际接入验证见 output/news-verification.json。

## 已安装的本地模型

- 判断模型：LightGBM，由本机 CPU 从公开历史行情训练。两个模型分别处理方向分类和未来五日内下探至少 3% 的事件；下探模型在独立区间做概率校准。方向分数未校准。
- 语言模型：Qwen3-4B-Instruct-2507，Q4_K_M GGUF，llama.cpp CPU 推理。模型与运行时已下载、按来源哈希校验，清单在 `models/download_manifest.json`。
- 当前使用 CPU。**没有声称 NPU 已加速或负责训练**。NPU 部署需要额外转换和兼容性实测，不在本版已实现功能中。
- 语言模型仅解释给定证据；程序显示原始数值，生成端限制数值复述并核对引用编号。检查通过不等于语义完全正确，仍需对照来源原文。

本程序只监听本机回环地址。前端不加载外部 CDN；外部请求主要携带股票代码或公司名称。持仓数量、成本和资产预算不发送给云端模型。不要把端口转发到公网。

## 换电脑或重新安装

当前目录已完成安装，可以直接启动。`.venv` 依赖本机 Python 路径，复制到另一台电脑后应重建：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe scripts\setup_models.py
.venv\Scripts\python.exe -m investlab.models
.venv\Scripts\python.exe app.py --open
```

如要运行验证：

```powershell
.venv\Scripts\python.exe -m pytest -q tests
.venv\Scripts\python.exe scripts\smoke_test.py
```

源码包不包含 2.4 GB 语言模型、推理运行时、虚拟环境或个人数据库，需按上述步骤恢复。自动资料、巡检和候选训练默认开启，不持续微调语言模型。训练运行期间不要关闭程序；修改代码后先停止再启动。

## 课程要求与新增功能（2026-10-29）
- 课程题目八项要求对应：用户画像、资产配置、市场与行业、组合风险、回测验证、个性化产品类别/策略、投资学堂、投资者保护。详见《课程要求实现对照.md》。
- 十题风险问卷、自定义透明评分、五维画像、最近50次记录、365天重评提醒。参考银行公开维度，不是正式银行测评。画像用于风险优化和适配提示，不静默削减用户手动投入目标。
- 咨询/配置可选短线5交易日和季度长线60交易日。长线为独立回归模型；当前测试与未见股票误差均未优于常数基线，界面明确提示，长期配置关闭其收益分数；自动晋升同时检查长期基线。
- 配置总资金须大于500元，默认稳健投入65%、进取投入85%，可填写拟投入金额（含估计买入费），可改单股股数。移除至少四只/单只硬上限，分散比例改为软目标；整手取整后再次补配。剩余不足一手时保留现金，不虚构碎股成交。点击推荐公司查看可切换区间的K线与成交量。
- 手动方案核对最新报价、100股整手和总预算后保存本地，不改变真实持仓。费用按0.1%估计，券商最低佣金等需用户另行核对。
- 行业页每行业取3只代表股计算20/60日相对表现；宏观官网连接失败时回退财经新闻并披露异常。组合风险页面每分钟刷新，风险是当前股票权重历史回放，不含现金，不能当成账户实际净值。
- 当前仅5日策略有保存的历史回放；60日提供真实预测误差。源码与报告记录未完成的长期前向验证、NPU部署等边界。PPT按用户要求暂缓，演示视频尚未录制。
新闻替换版验证：39项检查通过，含快讯解析、公司匹配、关联公司排除和来源失败降级。

## 机器人通知与探索（2026-10-30）
风险预警页已接入 Telegram 与企业微信群机器人。默认关闭，填写凭据和接收人后勾选授权并保存，再点击测试。凭据使用 Windows DPAPI 按当前系统用户加密，保存在本机 bot.key；不会回传页面或进入发布包。企业微信使用群机器人 Webhook，不支持个人微信。Telegram 需要 BotFather Token 与数字 chat_id，并先与机器人建立会话。网络必须能访问所选服务。
可选择仅发新风险事件或每1/4/24小时摘要；失败指数退避、最多5次，状态面板支持重试。接口接受消息不保证用户已读；超时可能导致重复。停用后停止发送，重新保存配置清空旧队列，只处理新事件。暂无 OpenClaw 和 QQ 适配器。
资产配置新增 ε 选择：0、10%、20%、50%。每个候选位置独立按 ε 概率从行业目录内的训练池外股票探索，实际数量有随机波动；排除独立留出组及特殊交易板块，所有新候选仍走同样的咨询门槛。不是全A股检索，也不会随机投资。探索记录在本机 exploration 目录，暂不根据尚未成熟的结果自动调权。54项隔离测试通过；未配置真实机器人，尚未验证第三方消息实际到达。
